ESP32 GT7 Dashboard

Version loading…

Flash the dashboard firmware directly from a compatible desktop browser. No PlatformIO installation is required.

  1. Connect the classic ESP32 board with a data-capable USB cable.
  2. Close serial monitors and other programs using its serial port.
  3. Select Install firmware, choose the port, and confirm.
  4. Leave the board connected until the installation finishes.

Installing replaces the firmware currently stored on the device. Web Serial is not available in every browser or on every mobile device.
